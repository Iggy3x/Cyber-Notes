Greita mentalinė formulė pentestingui

Kai matai failą, klausk:

Ar galiu įeiti į katalogą?  → reikia x
Ar galiu keisti failą?      → reikia w

Kas yra drwxrwxrwx

Linux failų teisės:

d rwx rwx rwx
│ │   │   │
│ │   │   └── kiti (others)
│ │   └────── grupė (group)
│ └────────── savininkas (owner)
└──────────── katalogas (directory)

rwx reiškia:

r – read (skaityti)

w – write (rašyti)

x – execute / enter directory
